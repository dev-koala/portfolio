# CLAUDE.md

Christabel Quaye's portfolio (Next.js 16, React 19, TypeScript, plain CSS). Single page, case studies in a native `<dialog>`.

See also `AGENTS.md` (generated by Next.js; keep it).

**Before doing anything, read `.claude/docs/README.md`** (index) and `.claude/docs/TODO.md` (things left to do).
**Before touching any copy, read `.claude/docs/CONTENT-RULES-AND-FACTS.md`.** Never invent content, metrics, URLs or contact details; use the placeholder patterns already in the code.

## Commands
- `npm run dev` · `npm run typecheck` · `npm run lint` · `npm run build` (all must pass before you finish)

## Where things are
- Copy and content: `data/` (typed). Edit copy there, not in components.
- Layout: `components/` (server components by default; only Nav, CaseStudyDialog, Toast, Enhance are client).
- Styles: `app/globals.css` (hand-written; tokens at the top). No Tailwind.
- Motion/behaviour: `lib/enhance/*.ts` (plain DOM scripts, each returns a cleanup). Do not move these into React state.
- Hooks the scripts depend on (don't rename without updating both sides): `#anatomy .pl[data-k] .veil .an-tag .an-card[data-i] #an #an-stage #an-hint`, `#work .proj`, `.a-volt`, `.a-dol`, `[data-par]`, `#beacon-svg`, `.canvas[data-cv] .roles .cur`, `[data-art]`, `.proj[data-i]`, `[data-open]`, `[data-sec]`, `.rv/.fd/.in`, `.go`, `[data-ph]`, `.js` on `<html>`.

## Conventions
- Keep `.claude/docs/` up to date in the same change as the code (especially TODO.md).
- Respect `prefers-reduced-motion` for any new motion. Hidden "before" states must be scoped to `.js`.
- Prettier: `npx prettier --write` on changed TS/TSX (100 columns). Leave `globals.css` formatting alone.
